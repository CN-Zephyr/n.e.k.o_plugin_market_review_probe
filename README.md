# Market Review Probe — 专用验收插件

仅供插件市场发布和审核验收。普通用户无需安装。

唯一功能是手动调用 `probe` 后返回固定测试标记。无第三方依赖，
不联网、不启动进程、不读写用户文件、不自动启动，不收集用户数据。

| 版本 | 变化 | 验收目标 |
| --- | --- | --- |
| 0.1.0 | 固定标记 `pilot-baseline` | 初次投稿与首版审核基线 |
| 0.1.1 | 只改版本号与说明文档，功能不变 | 无行为变化的更新自动通过 |
| 0.1.2 | 固定返回文本改为 `pilot-update` | 验证当前保守规则的上下文变化转人工 |

| 0.3.0 | 增加不由入口或启动逻辑调用的标准库网络代码夹具，目标为 example.invalid | 网络目标/API 变化转人工，已有 stable/beta 版本保持可用 |

0.2.0 的权限声明是审核分流测试夹具，不实现或调用剪贴板功能。
0.3.0 的 `network_review_fixture` 仅供静态规则识别；不注册插件入口，
不自动调用，不发送用户数据。烟雾测试会拦截网络函数，确认正常 `probe` 入口不联网。
禁止为了验收跳过初审、伪造 Actions 证明、使用生产管理员身份冒充作者，
或把后续测试版本同时混入首版源码。每个版本必须单独提交、打标签并由标准 Actions 构建。

灰度仅允许测试账号及本插件 ID 的交集；账号创建不代表已启用灰度。
首次审核和风险更新应由与作者不同的审核员处理。

说明更新：此版本用于验证文档变更的发布处理。
